# User Stories (selected)

## Onboarding & trust
1. As a user, I can verify my identity so that other users know I’m real.
   - Acceptance: verification status shown; unverified cannot request/offer help.

2. As a user, I can control what info is shared and when.
   - Acceptance: name/location sharing requires explicit consent per session.

3. As a user, I can only use the app if I am 18+.
   - Acceptance: adults-only enforced server-side; underage attempts blocked.

## Offering help
4. As a helper, I can go “Available” for the next X minutes/hours and choose categories.
   - Acceptance: availability auto-expires; helper can pause any time.

## Requesting help (vetted)
5. As a helpee, I can draft a help request and submit it for vetting.
   - Acceptance: request is not visible until vetted/approved.

6. As a helpee, if my request is rejected due to risk, I receive safe alternatives.
   - Acceptance: app shows resources (helplines/reporting) when appropriate.

## Session & chat
7. As both users, I can chat only during an active session window.
   - Acceptance: chat disabled after session ends; retention enforced.

## Safety & reporting
8. As a user, I can report abuse with evidence and feel heard.
   - Acceptance: report categories, optional screenshots, confirmation receipt.

9. As a user, I can quickly access urgent help options if needed.
   - Acceptance: visible “Get urgent help” button on key flows.

## Humanity Pulse
10. As the public, I can view aggregated trends without identities.
   - Acceptance: no personal identifiers; minimum thresholds to prevent re-identification.
