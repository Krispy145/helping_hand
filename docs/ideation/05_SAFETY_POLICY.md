# Safety Policy — Updated

## Age requirement
MVP is **18+ only**. Under-18 accounts are not permitted.

## Non-emergency disclaimer
Helping Hand is not an emergency service.

## High-risk categories policy
### “Need a place to stay tonight”
MVP stance: **Do not allow person-to-person accommodation requests.**
Reason: high risk for exploitation, coercion, unsafe situations.

Instead:
- provide “safe resources” routing (helplines, shelters, emergency options)
- allow “I need help finding official resources” as a safer alternative category

## Scam / fraud support routing
- Provide official reporting routes appropriate to the user’s region.
- Offer guidance prompts: “do not share OTPs”, “do not transfer money”, “keep communication in-app”.

## Mental health / loneliness support routing
If content indicates suicidal thoughts or urgent emotional distress:
- Provide a region-appropriate crisis helpline directory and quick-call options.
- Route the user to urgent resources before enabling community matching.

## In-app safety UX requirements (MVP)
- A prominent “Get urgent help” button in request creation and in-session screens
- “End session immediately” + “Report” always visible during session
- Consent gates for:
  - precise location sharing
  - media posting
- Meet-in-public default guidance (where applicable)

## Moderation actions
- Soft warning → temporary lock → permanent ban
- Rate limiting for suspicious actions (requests, reports, messages)
- Ban-evasion resistance (privacy-preserving device/account signals)

## Authority access roadmap
- MVP: provide links/call shortcuts to official routes (police, fraud reporting, helplines)
- V1+: generate an exportable “report pack” for authorities (metadata + evidence)
- V2+: partner integrations/formal escalation channels (legal review required)
