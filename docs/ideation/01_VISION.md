# Helping Hand — Vision

## One-liner
A privacy-first way to ask for help and offer help locally, while showing the world that humanity is still alive—without turning kindness into a leaderboard.

## Purpose
- Restore faith in humanity through real-world, verified, safe interactions.
- Make it easy to request help for everyday needs and emotional support.
- Provide an aggregated, public “Humanity Pulse” dashboard to reflect trends (good + bad), without incentivizing performative behavior.

## Core values
1. **Human first**: design for vulnerable moments.
2. **Safety before growth**: trust and abuse prevention are foundational.
3. **Privacy by default**: store the minimum necessary, retain briefly, encrypt where possible.
4. **No clout economy**: avoid follower counts, public rankings, “top helpers”, etc.
5. **Transparency**: explain what data is used and why, in plain language.

## What Helping Hand is NOT (non-goals)
- Not an emergency service (no “call police/ambulance replacement”).
- Not a gig-economy marketplace (no paid jobs, no bidding).
- Not a social network where popularity is the reward.
- Not a surveillance tool for “bad behavior”.

## Target outcomes
- Faster access to practical and emotional support.
- Lower loneliness via safe, verified connections.
- Clearer understanding of community “humanity health” via aggregated trends.
