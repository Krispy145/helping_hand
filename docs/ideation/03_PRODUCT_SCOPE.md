# Product Scope & Roadmap

## MVP (ship this first)
- Sign up (email) + identity verification (3rd party provider)
- Adults-only enforcement (18+)
- Profile basics (display name, optional photo)
- Availability toggle:
  - categories
  - radius + time window
- Request help flow:
  - category, short description, timeframe, optional photo
  - consent screens for sharing name + precise location during session
- **Request vetting gate** (automated checks; block malicious attempts)
- Match & connect:
  - helper discovery uses approximate location until accepted
  - accept/decline + safety checklist
- In-app chat between helper and helpee (session-bound)
- Report flow:
  - report helper misconduct
  - report helpee misuse
  - scam/fraud victim reporting (societal harm indicator; not victim blame)
- Humanity Pulse ingestion + basic public dashboard endpoints
- “Get urgent help” routes (emergency, non-emergency, helplines)

## V1 (safety + trust upgrades)
- Human moderation queue for escalated requests/reports
- Session check-ins (“I’m safe” prompts)
- Optional trusted contact share (on-device)
- Dispute workflow (review + appeals)
- Stronger abuse heuristics and graduated enforcement
- “Authority report pack” export (timestamps, metadata, evidence links)

## V2 (community maturity)
- Communities (opt-in neighborhood circles)
- Verified partner “safe places”
- More advanced analytics (region/category/time-series)
- Multilingual UX + accessibility pass
- Formal authority escalation integrations (legal review required)
