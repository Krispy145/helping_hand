# Helping Hand — Documentation Pack

This folder contains the product, safety, privacy, architecture, QA, and engineering guidance for the Helping Hand app.

## What this app is
Helping Hand is a human-centric platform for:
- People to **offer help** (Helpers)
- People to **request help** (Helpees)
- A public-facing **Humanity Pulse** dashboard that shows aggregated trends (positive and negative events) without turning kindness into clout.

## High-level principle
**Trust without surveillance.**  
We verify identity to reduce abuse, but we minimize stored personal data and avoid “social popularity” mechanics.
