# Phase Roadmap: Helping Hand

This document outlines the high-level phases of development, prioritizing safety and core utility in the MVP.

## Phase 0: MVP (The Safe Core)
**Goal:** Prove the "Safe Connection" hypothesis.
**Focus:** Vetting pipeline, Identity Verification, and basic Requests.
- **Features:**
  - Identity Verification (3rd party webhook stub).
  - Draft Request Creation (No public visibility).
  - **Automated Vetting Pipeline** (Regex + Mock ML/LLM).
  - Helper Discovery (Approximate Location).
  - P2P Chat (Session-locked, basic text).
  - Reporting (Basic immutable records).
- **Safety:** Hard-coded blocklists, strict category bans.

## Phase 1: Enhanced Trust & Reliability
**Goal:** Robustness and real-time safety.
**Focus:** Live AI integration and operational tools.
- **Features:**
  - Live integration with Toxicity/LLM APIs.
  - "Humanity Pulse" public stats dashboard options.
  - Moderator Admin Panel (for Appeals).
  - Push Notifications (Session alerts).

## Phase 2: Community & Warmth
**Goal:** Soften the "utility" feel with community features.
**Focus:** Positivity and retention.
- **Features:**
  - "Positivity Feed" (Consented stories).
  - User Profiles (Badges, stats).
  - Helper "Availability" specialized scheduling.

## Phase 3: Scale & Ecosystem
**Goal:** Geographic expansion and authority integration.
**Focus:** Performance and legal compliance.
- **Features:**
  - Authority Export Packs (for Police/Social Services).
  - Multi-region sharding.
  - Organization Accounts (Shelters, NGOs).
